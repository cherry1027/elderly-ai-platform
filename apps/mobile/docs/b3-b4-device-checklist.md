Record the tested mobile base SHA plus review source-snapshot hash, backend SHA,
device/OS/Expo Go version, display language, story language and result for every
case. Use only approved development accounts and fictional stories. Record

unnecessary account details. Mark unobserved cases PENDING, not PASS.

## Setup - separate owner approval required

Do not start a server or copy local JSON as part of applying/reviewing the patch.
After independent review, the owner must separately approve the development
account, client-safe mobile settings, current backend and personally controlled
network. Never use public/college/shared-Wi-Fi HTTP, tunnels, firewall changes,
backend `.env`, privileged credentials or paid providers for this checklist.
Preserve existing ignored files and real preferences/sessions; do not reset them
to manufacture a first-run check. Missing configuration is an honest unavailable
state, not authorization to invent a working endpoint.

The Windows reproduction instructions in the ZIP restore the exact source and
run protected offline checks without private settings. Native execution is a
different, later step. Android acceptance is separate from an Android JS export.

## English - tap-by-tap

1. After approved setup, open the exact reviewed normal app, not Sample Stories.
   Check English Welcome/Login or verified Home as appropriate. Existing signup
   is a local preview and Guest is unavailable. Do not send emails or activate it.
2. Open My Stories, select a fictional English story, then Share Memories. Check
   compact story/header, guarded Back and absence of root tabs in this workflow.
3. With no saved thread, verify clearly local guidance. With an existing thread,
   verify actual saved user/source and Memy messages with speaker labels. No
   fabricated saved question, waveform, playback or recognized-speech claim.
4. Scroll to an earlier message. Receive a new response through the separately
   approved fixture or deliberate turn: do not lose your reading position. Use
   the new-message/end control deliberately. VoiceOver focus must not be stolen.
5. Start recording: observe the actual microphone indicator, Recording state and
   elapsed time. Stop/Finish Speaking remains reachable at the largest text size.
   Keep the existing native 60-second stop; do not infer a new recording limit
   from the separate 90-second/25 MB upload validation bounds.
6. Stop. Confirm an UNSENT local recording, not saved wording, appears. Stopping
   must make no upload or conversation request. Check consent is explicit and
   unchanged. Discard/record again only through genuine supported controls.
7. Give consent and explicitly upload. Observe truthful progress and errors.
   Returned saved transcript text appears within the thread. It remains labelled
   FIXED FICTIONAL SIMULATION, not speech recognition. Show each source only once
   when transcript and user-message IDs identify the same saved record.
8. Explicitly process the saved transcript through the separate conversation
   action. Observe actual persisted simulated Memy text, then another safe
   recording opportunity. Rapid taps must not duplicate uploads or turns.
9. During recording/unsent/upload uncertainty, try visible and hardware Back if
   supported. Stay preserves local work; deliberate leave invokes existing
   cleanup. Do not imply a possibly completed upload was rolled back.
10. Review Memories, then return to the same conversation/autobiography route.
    Under an approved local fixture, verify `1974 -> 1975` recovery, exact 429/503
    waiting and deliberate reread/retry. Expiry must send nothing. Unknown/plain
    503 remains uncertain. Never flood a hosted service to force errors.
11. Open My Autobiography. Merely opening reader/actions/sources makes no write.
    Read paragraphs at large text. Keep simulation/manual-review/conflict notices
    visible. Edit is obvious and Continue My Story is easy to reach.
12. Choose Edit. Enter two fictional paragraphs. Done typing and blur must keep
    words without saving. Open the keyboard and reach input, validation, Save and
    Back at large text. Save explicitly; reopen through fresh reads and verify
    generation unchanged, revision updated and manual wording unverified.
13. Make another unsaved change; Back -> Keep editing retains it. Back -> Leave
    without unsaved wording discards local RAM only. An uncertain save requires
    Check saved wording; it is never described as definitely canceled.
14. Open Saved Autobiographies. Choose an actual older generation with a manual
    edit; note its real generation and revision. It is not a flattened version
    counter. Partial/capped list warnings remain honest. Reopening rereads it.
15. Read Edit History and original generated wording, then Source Memories. Prior
    wording/evidence stays read-only; no Restore/Delete/Merge control is invented.
    Return to the exact older selected autobiography.
16. Continue My Story -> chat -> Review Memories -> chat -> Back to My
    Autobiography. Confirm the same selected older generation, not latest. No
    autobiography is generated just by continuing.
17. Choose Create Another Autobiography, read preservation notice, cancel first
    (no write). Confirm deliberately later. Inspect the actual returned identity:
    it may reuse any earlier matching generation rather than version + 1. Earlier
    manual wording and previous-selection controls remain available.
18. From the selected SAVED generation/revision, open PDF preparation. Entry and
    history viewing do not POST an export. Select only supported title-page/page
    numbering options. Explicitly Prepare, then explicitly Share or Save.
19. Inspect an actual historical PDF after later edits/title changes. Verify its
    audited title/generation/revision rather than today's text. Cancel the share
    sheet: the app must not claim it saved/sent. Return after owned revalidation
    to the selected autobiography. A delayed return must not override newer
    deliberate navigation. No private-cache deletion while the sheet needs it.
20. Under approved fixtures: interrupted/uncertain saves/exports, delayed results,
    background/foreground, sign-out and account change. Old-owner content must
    disappear; late responses cannot revive it. Background may clear unsaved
    private RAM by design. Never claim durable unsaved recovery.
21. Repeat with VoiceOver, reduced motion, long labels, smallest practical screen,
    largest Dynamic Type and orientation changes. Speaker identity is spoken,
    controls are at least 56 units, composer does not obscure controls/messages,
    source language is correct and scrolling/focus remain calm.

## Svenska - steg för steg

1. Öppna samma granskade normala app efter separat godkänd konfiguration. Välj
   Svenska. Logga in avsiktligt med ett godkänt testkonto; Hem visas efter
   verifiering. Registrering är fortfarande en lokal förhandsvisning och
   gästläge är inte tillgängligt. Skicka inga mejl.
2. Öppna Mina berättelser och en fiktiv svensk berättelse -> Dela minnen.
   Kontrollera rubrik, skyddad Tillbaka och att rotflikarna inte visas här.
3. Läs tråden: användarens sparade källmeddelanden och Memys svar har tydliga
   talarnamn. Utan historik visas lokal vägledning, inte en påhittad sparad fråga.
4. Starta inspelning -> kontrollera faktisk tid och tydlig inspelningsstatus ->
   Stoppa/Avsluta. Den oskickade lokala inspelningen får inte kallas sparad.
   Stopp får inte automatiskt ladda upp eller bearbeta ett samtal.
5. Ge uttryckligt samtycke -> ladda upp -> läs den återgivna sparade texten i
   tråden. Meddelandet måste tydligt beskrivas som fast fiktiv simulering, inte
   taligenkänning. Samma käll-ID får inte visas två gånger.
6. Välj den separata uttryckliga bearbetningen -> läs faktiskt sparat simulerat
   Memy-svar. Prova snabba tryck, läsning av äldre meddelanden och kontrollen för
   nya meddelanden utan tvingad rullning eller förlorat VoiceOver-fokus.
7. Prova Tillbaka under inspelning, oskickad inspelning och osäkert resultat.
   Stanna behåller arbetet; lämna använder befintlig städning. Ett eventuellt
   slutfört anrop får inte beskrivas som säkert ångrat.
8. Granska minnen och återvänd. Med separat godkänd testfixtur: rättelsen
   `1974 -> 1975`, vänteläge för 429/503 och uttrycklig omläsning/nytt försök.
   Väntetidens slut skickar inget anrop. Okänd 503 är fortfarande osäker.
9. Öppna Min självbiografi. Läs stycken, simuleringsinformation och uppgift om
   manuell granskning. Att öppna läsare, meny eller källor får inte skriva data.
10. Redigera två stycken med å/ä/ö. Klar och tappat fokus sparar inte. Kontrollera
    tangentbord, feltext, Spara och Tillbaka med stor text. Spara uttryckligt,
    öppna igen och kontrollera samma generation samt rätt manuell revision.
11. Ändra utan att spara -> Tillbaka -> Fortsätt redigera. Orden ska finnas kvar.
    Lämna avsiktligt rensar bara osparat lokalt arbete. Kontrollera osäker
    sparning via sparad formulering innan ett uttryckligt nytt försök.
12. Öppna sparade självbiografier -> välj en verklig äldre generation med egen
    redigering -> läs redigeringshistorik, ursprunglig text och källminnen.
    Generation och revision är skilda. Inga påhittade återställningsfunktioner.
13. Fortsätt min berättelse -> samtal -> granska minnen -> tillbaka till samma
    valda självbiografi. Fortsättning skapar inte automatiskt en ny självbiografi.
14. Välj att skapa en självbiografi till -> läs information -> avbryt först.
    Bekräfta sedan avsiktligt. Kontrollera faktiskt svar: en äldre matchande
    generation kan återanvändas. Tidigare manuell text ska förbli tillgänglig.
15. Öppna PDF för sparad generation/revision -> välj stödda alternativ -> skapa
    uttryckligt -> dela eller spara uttryckligt. Kontrollera äldre PDF:s ursprungliga
    titel och revision efter senare ändringar. Avbryt delning och kontrollera att
    appen inte påstår att filen sparades/skickades. Återvänd till rätt val.
16. Med godkända fixturer: avbrott, bakgrund/förgrund, fördröjda svar, utloggning
    och kontobyte. Privat RAM kan rensas enligt policyn; gamla data får inte visas
    för ett nytt konto. Kontrollera stor text, VoiceOver, minskad rörelse, rullning
    och att mikrofon/Stoppa och andra åtgärder alltid kan nås.
